Following make lines work for running on Epyc 7302 test machines at Steno:

make COMPILER=ifort -j HW='-march=core-avx2 -align array64byte -qopt-assume-safe-padding -vec-threshold1' OPT='-O3 -ip' DEBUG='-g -traceback -check pointers' -j 64
make COMPILER=ifort -j HW='-march=core-avx2' OPT='-O1' DEBUG='-g -traceback -ftrapuv' -j 64 
make COMPILER=ifort -j HW='-march=core-avx2' OPT='-O1' DEBUG='-g -traceback -ftrapuv -fp-model source -fp-model fast=1' -j 64


Anything missing "-check pointers" and with optimization above "-O1" crash. E.g.

make COMPILER=ifort -j HW='-march=core-avx2' OPT='-O3' DEBUG='-g -traceback -ftrapuv' -j 64
make COMPILER=ifort -j HW='-march=core-avx2' OPT='-O2' DEBUG='-g -traceback -ftrapuv' -j 64
make COMPILER=ifort -j HW='-march=core-avx2' OPT='-O2' DEBUG='-g -traceback -ftrapuv -fp-model source -fp-model fast=1' -j 64
make COMPILER=ifort -j HW='-march=core-avx2' OPT='-O3 -no-vec' DEBUG='-g -traceback -ftrapuv -fp-model source -fp-model fast=1' -j 64
make COMPILER=ifort -j HW='-march=core-avx2' OPT='-O2 -no-vec -fno-inline -no-ip' DEBUG='-g -traceback -ftrapuv -fp-model source -fp-model precise' -j 64


To run on the Steno test machine first reserve the full node with e.g.

srun -p demo --constraint=epyc7302 --nodes=1 --cpus-per-task=64 --ntasks-per-core=2 --pty /bin/tcsh
srun -p demo --constraint=epyc7452 --nodes=1 --cpus-per-task=128 --ntasks-per-core=2 --pty /bin/tcsh

Then run the experiment:

srun taskset -c 0-15 env OMP_NUM_THREADS=16 KMP_AFFINITY="verbose,granularity=thread,scatter,1,0" ./dispatch.x 512_bench.nml
