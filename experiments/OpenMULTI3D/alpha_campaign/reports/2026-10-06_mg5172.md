# Alpha campaign: Mg I 5172 NLTE, single run against stage-2 SED

Decision 3 of `2026-10-06_phase7.md`. In metal-poor giants the single NLTE run gave a larger
NLTE EW for Mg I 5172.7 than the b4 stage-2 SED did, by up to 12 %.

## Cause

The difference comes from Fe I 5171.596 (χ = 1.485 eV, log gf = −1.79 in
`vald_atoms_abo.txt`). This line lies 1.09 Å blueward of Mg I 5172.684, inside the
±1.5 Å EW window of `delta_maps.LINES_SED`. Mg I 5172 itself is the same in both paths.

- The single run `mg/` has only the Mg atom, so Fe I 5171.6 is in LTE in its NLTE spectrum
  as well as in its LTE spectrum.
- The stage-2 SED (`sed_namelist`) reads the Mg and the Fe departures, so its NLTE spectrum
  has Fe I 5171.6 in NLTE. Fe I is over-ionised in metal-poor giants, so the blend weakens
  and the window EW drops. The window's Δ_NLTE then attributes that Fe effect to Mg.

Evidence: local 1D runs of t55g25m30 with the worktree build (base d28758669, the code
of `bin/37f757d56`), on the cluster's inputs and departures.

| Run | Atmosphere | Path | 5172 NLTE / LTE [mÅ] | 5528 NLTE |
|---|---|---|---|---|
| `b8g/av3d/t55g25m30/mg` (cluster) | avg3d8g | single run, Mg | 190.30 / 204.61 | 19.51 |
| local SED on its Mg + Fe departures | avg3d8g | stage 2, Mg + Fe atoms | 169.72 / 204.61 | 19.48 |
| local SED on the same departures, Mg atom only | avg3d8g | stage 2, Mg atom | **190.30** / 204.61 | 19.51 |
| local single run, new build | avg3d (b4) | single run, Mg | 192.26 / 208.27 | 19.43 |
| `b4/sed/av3d_t55g25m30` (cluster, and rerun locally: identical) | avg3d (b4) | stage 2, Mg + Fe atoms | 170.53 / 208.27 | 19.40 |

With the same atoms the two paths agree to print precision in all three Mg windows. A
single-run namelist that reads the saved departures (`read_departures`, `maxiter=0`) also
gives 190.30. Removing the Fe atom from the SED recovers the full 20.6 mÅ. In the SED − single
flux difference the whole 20.55 mÅ lies in 5171.18–5172.40 Å, peaking at 5171.60 Å
(normalised flux 0.52 → 0.76). At the Mg core the flux is 0.159 in both runs.

The candidates in the assignment do not contribute. Level matching, gf, broadening,
line scattering, the iteration's background opacity, saved against in-memory departures
and the build all leave the Mg line unchanged.

Other points:

- **The phase-7 comparison was not on one atmosphere.** "190 against 170, LTE 205 against
  208" set the b8g single run (avg3d8g) against the b4 SED (avg3d). The table above shows
  the same 20 mÅ on one atmosphere, so the conclusion holds.
- **Why only 5172 and metal-poor giants.** No other pilot window contains a line of the
  other atom with a sizeable NLTE effect: 5528 differs by 0.2 % and 5711 by 0. Fe I NLTE
  weakening grows towards low [Fe/H] and low log g. At [Fe/H] = −4 the blend becomes too
  weak to matter, and near solar [Fe/H] the Fe I departures are small.
- The b4 single runs (`b4/av3d/<m>/mg`, `f63e2fc9`, `exclude_elements='Mg'`) take the Mg
  lines from the atom (5528 NLTE: 24.4 against 19.4 mÅ from the list) and are not part
  of either comparison.
- A small side observation, not investigated: Fe I 6430.8 and Fe II 6432.7 differ
  between the `fe/` single run and the SED by 1 % and 5 %, in the LTE spectrum too
  (≤ 0.04 mÅ, weak lines).

## Which path is right

For a Mg abundance correction, the single run is right. It changes only the Mg
populations between the NLTE and the LTE spectrum, and the slope dlogEW/dA comes from the
Mg ±0.3 sets of `b1`, which also keep the blend fixed. The SED gives a realistic NLTE
spectrum, but its 5172 window mixes the Fe I correction into the Mg one. The code
behaves correctly in both paths, and no source fix is needed.

## Consequences for existing tables

Δ_NLTE(Mg 5172), b8g single run − b4 SED, from `N_p7_b8g.csv` and `N_p7_b4.csv`
(min / median per group [dex]). The atmosphere change alone gives at most 0.026, as 5528
shows.

| [Fe/H] | giants (log g < 3.5) | dwarfs |
|---|---|---|
| −4 | −0.278 / −0.124 | −0.087 / −0.028 |
| −3 | −0.364 / −0.108 | −0.161 / −0.063 |
| −2 | −0.166 / −0.032 | −0.114 / −0.017 |
| −1 | −0.023 / −0.010 | −0.036 / −0.011 |

- **Correct:** `b8`, `b8g` (`own_nlte`, single runs) for all Mg lines, and every 3D Mg
  NLTE value of the pilot at [Fe/H] < 0. The 3D runs used there (`_3dmg`, `_3dmg4`) carry
  Mg departures only. `_3dmgfe` exists for t55g45m00 and t60g40m00 only, where the effect
  is ≤ 0.01 dex.
- **Contaminated for Mg I 5172 at [Fe/H] ≤ −1:** every NLTE value from an SED with Fe
  departures. These are `N_p7_b4` (`b4/sed`); the Stagger-file <3D> column of every N table
  (`ew_old_nlte`, `dA_nlte_old`, `dA_3d_nlte_old`, from `b2/sed`); the A2/B2 modes
  (`b2/sed`); and the MARCS twins' D_nlte in `pilot_compare` (`b6/sed`, `p1sed/<m>/marcs`).
- Phase 7's large Mg tail (Set − b4, 5 % quantile of Δ_NLTE Mg I −0.134 and −0.111 dex) is
  this artefact. It does not come from the <3D> recipe.

## Recommendation

1. Keep Mg I 5172 in the training set for maps built on single runs (b8/b8g). Do not
   exclude it.
2. Do not use Mg I 5172 NLTE values from Mg + Fe SEDs at [Fe/H] ≤ −1. Where a table needs
   them (the Stagger-file and MARCS-twin columns, b4), make a Mg-only SED on the existing
   departures (`sed_namelist(dep, comp, atoms=[PILOT_MG['file']])`). This is a 1D run of
   about 30 s, and its Mg windows equal the single run's.
3. Optional: an asymmetric 5172 window that stops before 5171.6 Å would make the EW
   independent of how the blend is treated. It changes 5172's EWs and slopes in every
   table, though, so it only pays off if SED-based Mg values have to stay.
