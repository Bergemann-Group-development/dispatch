\fort{&output_params} & Meaning\\
\midrule
\fort{save_populations} & Write the level populations (default \fort{T}).\\
\fort{save_every} & Write the populations every that many NLTE iterations as well (default 0, only at the end; Sec.~\ref{sec:stopping}).\\
{\fort{save_rates},\\\fort{save_resolved},\\\fort{save_Inu},\\\fort{save_chi},\\\fort{save_Snu},\\\fort{save_Jnu},\\\fort{save_cntrbf}} & Which further fields are written (Sec.~\ref{sec:output}).\\
\fort{depression_cntrbf} & With \fort{save_cntrbf}, save the depression contribution function (default \fort{T}) or, with \fort{F}, the intensity contribution function (Sec.~\ref{sec:cntrbf}).\\
\fort{rt_to_file} & Keep the exit planes of frozen columns on disk (default \fort{T}).\\
\fort{bound_free_in_output} & Add the bound-free transitions of the model atoms, with their NLTE populations, to the output pass (default \fort{F}). Without it the output spectrum lacks the photo-ionisation opacity of the atoms' levels.\\
\fort{set_file} & Abundance sets for ladders of calculations in one process.\\
