\fort{&run_params} & Meaning\\
\midrule
\fort{n_windows} & Number of wavelength windows (one set of tasks each). Default: twice the thread count, doubled while the memory estimate exceeds 70\,\% of the memory limit.\\
\fort{lam_tolerance} & Merge wavelength points closer than this (default $0.001$ {\AA}).\\
\fort{rotate_atmos} & Rotate the atmosphere for each ray (required by the Hermite solvers in 3D; set by the \File{3d} preset).\\
\fort{mem_limit_gb} & Limit of the pre-run memory check and of the automatic \fort{n_windows} choice (0: physical memory of the machine, on a batch node the whole node; negative: no check, and \fort{n_windows} defaults to twice the thread count).\\
\bottomrule
