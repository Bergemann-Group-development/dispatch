Documentation
=============

Auto-generated documentation
----------------------------

The `auto-generated documentation <https://dispatch.readthedocs.io/en/latest/doxygen/index.html>`_
is produced by *doxygen*, and primarily serves two purposes:

1) It illustrates, comprehensively and accurately, the relations
between modules, data types, and shows their data and procedure parts.

2) It shows the contents of special comment blocks accompanying
modules, data types, and their procedures.  This provides commentary
that typically discusses the relations mentioned in item 1).


Bitbucket Wiki
--------------

The `Bitbuck wiki <https://bitbucket.org/aanordlund/dispatch2>`_ is
used primarily to document and discuss tips and tricks related to
developing and using the code.

Google docs
-----------

The `Google docs <https://drive.google.com/drive/u/0/folders/0B-4hLWbLQz2SfjFhMkVDYlh5N2VMdzBOM014NWY0NHFZWmFiYjNxZmNlWFJWbVp4QnA1SVk>`_
are used for

1) Interactive and collaborative editing of documents discussing
code related issues (including research proposals), and

2) Ease of producing documents containing descriptions and
discussions of results -- numerical and / or scientific,
where one can easily include tables, graphics, and animations.
